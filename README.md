🛳️ Titanic Dataset – Exploratory Data Analysis (EDA)
This project performs an in-depth Exploratory Data Analysis (EDA) on the Titanic dataset to uncover patterns, trends, and relationships among features influencing passenger survival. Using Python libraries like Pandas, Matplotlib, and Seaborn, the analysis explores demographic, socio-economic, and ticketing data. Key steps include:

Data cleaning and handling missing values

Univariate and multivariate visualizations

Feature engineering (FamilySize, IsAlone)

Correlation analysis and survival insights

Classification modeling and evaluation (Random Forest achieved highest accuracy: 83%)

📊 The goal is to understand the dataset structure, highlight survival influencers, and prepare data for machine learning.
